# InkBlob Alpha 穩定化調整 — 2026-10-20

本輪完成程式調整及本機回歸驗證，尚未部署新版合約，未執行使用真實錢包的付費／簽名端到端流程。版本仍屬 Alpha 整合階段。

## 已完成

- 遷移到 Sui 2.37、目前的 dApp Kit／Walrus SDK 與 gRPC；以產品實際轉接層唯讀驗證 Testnet Clock 及動態欄位。
- 以獨立遞增 revision 保護筆記更新，分離本機編輯時間；session 與一般交易都拒絕執行失敗的結果。
- 修正保存中繼續輸入、背景 metadata 覆蓋草稿、讀取失敗被當成空內容、建立筆記失敗刪掉已輸入內容等情況。
- 加入依網路／帳號／notebook／note 隔離的加密本機草稿，保留原始 revision；提供匯出副本及重新載入已保存版本的入口。
- 背景保存不會自動要求錢包簽名或重複詢問 session 授權；只有有效、綁定該 notebook 的 session 才會自動提交。
- 帳號切換重建加密與 session 狀態，隔離並清理 React Query 快取；移除重複 provider。
- notebook 採各自派生的內容金鑰；分享一本不會揭露其他 notebook 的金鑰。
- 加入擁有者可實際提交的分享／session 撤銷入口，避免依賴收件人持有的物件。撤銷後 session 合約寫入被拒絕。
- 統一錢包與 session 的 raw Walrus blob 編碼，記錄真實 blob object id；保存期限預設 30 epochs，可從編輯器延長並讀取實際到期 epoch。
- metadata 重試可重用已上傳 blob；錢包流程只重試資料傳輸，不重複註冊付款。
- 改善手機標題自動高度、設定分頁、主題透明度、焦點圈限與回復；修正 JSON 被當成預覽文字／字數。
- 改善首頁 logo 對比與保存期限／費用說明，移除永久保存承諾；支援減少動態效果。
- 編輯器與儲存模組按需載入；正式建置移除 console；移除前端注入 Gemini 私密金鑰的設定。
- 新增 CI、部署 manifest 產生器、部署唯讀檢查及 v2 相容性文件，更新過時 README 與歷史文件標記。

## 發布前的必要工作與限制

1. 新增的合約欄位及 notebook 金鑰範圍是破壞性相容變更，需要新的 v2 部署與 notebook；不得直接覆蓋舊部署或既有資料。範例環境刻意不提供舊 package id。
2. 舊資料需要保留可驗證的備份與舊版本讀取方式；自動遷移及匯入尚未實作。
3. 分享撤銷會停止寫入、移除鏈上包裝金鑰，不能收回對方已取得的內容／金鑰。未來讀取的密碼學撤銷仍需金鑰輪替設計。
4. session 撤銷不會自動回收裝置錢包中剩餘的 SUI／WAL。
5. 合約顯示用時間仍採 epoch 粒度；並發保護已改用 revision，不依賴該時間。
6. 需要依部署文件完成兩帳號、兩裝置、實際儲存與續期、撤銷、斷網及真實錢包的發布驗收。CI 配置已加入，但遠端 CI 執行結果不在本次驗證範圍。

詳見 [v2 部署與發布驗收](../develop/deployment-v2.md)。
